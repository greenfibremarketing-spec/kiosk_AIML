Frontend Integration (How to Run in Kiosk UI)

Copy-paste this module into your kiosk frontend. Hide the Greeny avatar until the intro video finishes or the user clicks "Meet Greeny". 

// 1. Import player module from the backend
import { playKioskIntro } from "https://YOUR_BACKEND_HOST/media/intro-player.js";

// 2. Play before connecting or during startup
const introContainer = document.getElementById("intro-container");
const avatarContainer = document.getElementById("avatar-container");

avatarContainer.hidden = true;
introContainer.hidden = false;

// Plays 5 Cloudinary videos (1 -> 3 -> 5 -> 4 -> 2)
const result = await playKioskIntro(introContainer, {
    apiBase: "https://YOUR_BACKEND_HOST"
});

// result is: 'intro_done' | 'intro_skipped' | 'intro_failed'
introContainer.hidden = true;
avatarContainer.hidden = false;

// 3. Connect to WebSocket or trigger greeting
const ws = new WebSocket(`wss://YOUR_BACKEND_HOST/ws/${sessionId}?v=2&auto_greet=1`);
